About

DR Level Viewer opens a Draw Rider level file and draws it the way the game does — the same rotated rectangles, the same round ends, one unit to one pixel. Nothing is uploaded anywhere: files are read in the browser and never leave the machine.

It edits them too. The strip on the left holds the game's own tools — lines and a curve brush over either layer, an eraser with a radius, a pipette, the eleven object types, start and finish — plus a magnet that begins each stroke where the last one ended. Text writes with any font you hand it and turns the letters into lines. Choose picks a line or an object to change: colour, width, rounding, rotation, and shift gathers several lines to edit at once. Vehicle, game mode and background are set in the panel, every step is undoable, and New level starts an empty one.

It also builds levels. Pixelate image turns a picture into one record per pixel. Geometrize image recreates it out of shapes, fitting them one at a time, and reads or writes the same shape JSON the Geometrize web demo uses.
